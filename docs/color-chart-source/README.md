# 官方色卡原图

COLOR LOMO 固色发膜商品详情页素材，是 `color_effect_matrix.r_real` 系列字段的唯一出处。

## 为什么要版本化
颜色数据全部从这批图逐格采样得来。留着原图，任何人都能重新采、能核对采样框对不对，
也能在换算逻辑改动后重跑。丢了这批图，那些 RGB 值就成了无法追溯的魔法数字。

## 采样口径
- 每张详情页的「发膜干发补色染色效果」表：`使用后` 那一行 = 该色系在各底色度数下的呈色
- 「固色适用发色」六宫格 = 该色系的命名变体（玫瑰金／樱花粉／芭比粉…），存入 color_variant

## 重要边界
这是**固色发膜**的效果，不是染发剂。官方标注的最低适用度数（蓝 8 度、粉 8 度、紫 7 度）
比知识库里染发剂的 `minDyeableLevel` 高。
**两套数据只在渲染层汇合：能不能染查知识库，长什么样查这里。**
