## 一、核心痛点洞察

产品痛点源于我作为一个染发爱好者的个人需求。我经常在刷抖音和小红书的时候，看到博主们美丽的发色就忍不住想跟着教程去跟练，但往往容易"翻车"。

因为每个人的发色、发长和发质都不一样，博主的方法并不一定适合我。比如：

1. **药剂用量问题**：博主的头发可能比我短，我按照教程买来的染膏就会不够用，导致染不均匀。
2. **底色差异**：博主的底色可能漂得比我更白，同样的染膏在我头上可能根本不上色。
3. **颜色偏差**：博主是黑发直染出的漂亮"海王红"，但我这种已经漂过的头发，直接上红色染膏可能会变成灾难般的"荧光火龙果粉"。

在吃过这么多亏之后，我就在想，能不能有一款产品能让我正式上手之前先判断一下：

- (a) 我到底能不能染成博主那样的效果？
- (b) 如果可以，我该买什么样的染膏？
- (c) 染膏应该用什么样的比例去调配？
- (d) 实际上头时有哪些注意事项？

这就是产生这款产品的初衷。

## 二、系统技术架构

```
┌─────────────────────────────────────────────────────────────┐
│ 输入层    头发照片 │ 目标色照片 │ 博主视频/链接 │ 语音指令    │
└──────┬────────┬───────────┬──────────────┬─────────────────┘
       ▼        ▼           ▼              ▼
┌─────────────────────────────────────────────────────────────┐
│ AI 理解层                                                    │
│  Claude Vision    Whisper+Claude    Claude Haiku            │
│  (分析头发参数)   (视频→步骤+知识)  (语音意图识别)            │
└──────────────────────┬──────────────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────────────┐
│ 知识库 RAG（30 篇小红书笔记爬取 + 抽取）                       │
│  products.json (23 个产品+原话评价)                          │
│  knowledge.json (44 条结构化知识)                            │
└──────────────────────┬──────────────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────────────┐
│ Claude Opus 4.7 个性化生成                                   │
│  可行性判断 │ 选品+评价 │ 调配比例 │ 操作步骤                 │
└──────────────────────┬──────────────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────────────┐
│ 输出层    5 步分屏 UI │ TTS 朗读 │ 自动闹钟 │ 博主帧轮播       │
└─────────────────────────────────────────────────────────────┘
```

**关键技术栈**：Next.js 16 + Claude Opus 4.7 / Haiku 4.5 + Whisper + qwen3-tts + ffmpeg + Playwright

**技术亮点：真实可靠的小红书知识库**

我用 Playwright 爬取了 30 篇小红书染发笔记，再用 Claude 把这些笔记的内容结构化成两份知识库：

- **`products.json`**：23 个真实染膏产品，每个产品都附带从小红书原帖摘出的用户原话评价（包括正面和负面）+ 淘宝实时价
- **`knowledge.json`**：44 条结构化知识，覆盖底色匹配、避坑警告、价格情报、操作技巧等 7 个类目

生成个性化方案时，知识库会被注入 Claude prompt，并设置硬性规则：**所有产品 pros/cons/评价必须来自原话引用，调配比例必须有出处**。

这样信息真实可靠，每一条推荐都能追溯到具体的小红书笔记，一定程度上避免了 AI 幻觉。

## 三、多模态交互流程（UX）

5 步分屏，对应用户的 4 个核心问题：

```
Step 1 上传 → Step 2 判断 → Step 3 选品 → Step 4 调配 → Step 5 操作
  ↑              ↑           ↑           ↑           ↑
头发+目标色      (a)能不能   (b)买什么   (c)怎么调   (d)怎么操作
+博主视频       染成那样?    染膏?      比例?       语音陪同
```

**多模态对应**：

| 模态 | 用在哪 |
|------|-------|
| 📸 图像 | 输入头发照片→Vision 分析；输出博主连续帧轮播 |
| 🎬 视频 | ffmpeg 抽音频→Whisper 转录→Claude 聚合→Vision 选帧 |
| 🎤 语音 | MediaRecorder+VAD 静音 1 秒自动识别→Claude Haiku 理解口语意图 |
| 🔊 朗读 | qwen3-tts-flash 进入操作步骤自动播放 |
| ⏰ 系统 | 检测"停留 X 分钟"→主动弹闹钟→系统通知 |

**为什么需要语音**：染发时手上沾满药剂，无法触屏。说完静音 1 秒自动识别，听得懂"我弄好了下一步"「帮我定个闹钟」「别说了」等口语。

## 四、商业与社会价值

**商业价值**
- 染膏品牌精准广告（按用户底色/目标色定向）
- 推荐链接电商分成
- 同架构可复用美甲/化妆/烘焙等"教程跟做易翻车"场景

**社会价值**
- 降低普通女生尝试小众发色的门槛，减少因翻车的消费浪费
- 打通博主内容的"最后一公里"——从被动观看到主动使用
- 未来全语音流程可服务不擅长智能机的中老年用户
